# 로컬 모드 (Local Mode)

## 개요

로컬 모드는 ScoreBlacker 모드의 로컬 테스트 및 오프라인 플레이 환경을 지원하는 모드입니다. 게임을 오프라인 상태에서 실행하며 모드의 기능을 안전하게 테스트할 수 있습니다.

## 주요 특징

### 1. 오프라인 환경
- 인터넷 연결 없이 게임 실행 가능
- 네트워크 요청 차단
- 로컬 데이터만 사용

### 2. 테스트 기능
- 모드의 스코어 조작 기능 안전 테스트
- 판정 시스템 분석 및 검증
- 키보드 단축키 기능 확인

### 3. 개발 편의성
- 빠른 반복 테스트
- 디버그 로그 출력
- 분석 정보 콘솔 로깅

## 설정 및 활성화

### 로컬 모드 활성화 방법

1. `SceneDetector.cs`에서 `UseLocalMode` 플래그 설정:
```csharp
private static bool UseLocalMode = true;
```

2. 필요한 설정 변수 조정:
```csharp
public static float ScoreMultiplier = 1.0f;        // 점수 배수
public static float AdditionalScore = 0.0f;        // 추가 점수
public static bool DebugMode = true;               // 디버그 모드 활성화
```

### 로컬 모드에서의 동작

- **판정 처리**: 일반 모드와 동일하게 작동
- **점수 조작**: 테스트 목적의 점수 조작 활성화
- **디버그 출력**: 모든 분석 정보를 콘솔에 출력
- **네트워크**: 서버 통신 시뮬레이션 (선택사항)

## 사용 사례

### 1. 점수 시스템 테스트
```
로컬 모드에서 다양한 점수값으로 테스트
→ 점수 조작이 올바르게 작동하는지 확인
```

### 2. 판정 시스템 분석
```
게임의 판정 로직 분석
→ Perfect, Great, Good, Miss 등의 판정 처리 확인
```

### 3. UI 연동 테스트
```
스코어보드, 콤보, 하이스코어 미터 등 UI 업데이트 확인
→ 모든 UI 요소가 올바르게 동기화되는지 검증
```

## 로컬 모드 vs 온라인 모드

| 항목 | 로컬 모드 | 온라인 모드 |
|------|---------|----------|
| 네트워크 | 불필요 | 필수 |
| 점수 전송 | 미지원 | 지원 |
| 테스트 용도 | ✓ | ✗ |
| 실제 플레이 | ✗ | ✓ |
| 디버그 로그 | 활성화 | 선택사항 |

## 주의사항

1. **로컬 모드에서의 점수는 서버에 전송되지 않습니다**
2. **실제 온라인 플레이 전에는 온라인 모드로 전환하세요**
3. **디버그 로그는 성능에 영향을 줄 수 있으므로 필요시에만 활성화하세요**

## 지원하는 기능

### 로컬 모드에서 지원
- ✓ 스코어 조작
- ✓ 판정 강제 변경
- ✓ 키보드 단축키
- ✓ 분석 및 로깅
- ✓ 일시정지 제어

### 로컬 모드에서 미지원
- ✗ 점수 랭킹 전송
- ✗ 업적 동기화
- ✗ 멀티플레이 기능
- ✗ 온라인 리더보드

## 문제 해결

### 로컬 모드가 작동하지 않을 경우

1. `UseLocalMode` 플래그가 `true`로 설정되어 있는지 확인
2. 콘솔 로그에서 오류 메시지 확인
3. `DebugMode`를 활성화하여 상세 로그 확인
4. 게임을 재시작하고 재테스트

### 점수 조작이 작동하지 않을 경우

1. `ScoreMultiplier`와 `AdditionalScore` 값 확인
2. 판정 시스템이 정상 작동하는지 확인 (Perfect 판정 여부)
3. 스코어 패치가 올바르게 적용되었는지 확인
